Install

Up and running in a minute

Tracker isn't on the Play Store yet. You install it straight from the APK, which takes three quick steps.

download

Download

Tap Download APK on your Android phone to get the latest release from GitHub.

lock

Allow the install

Open the file. If Android asks, allow Install unknown apps for your browser or file manager.

fitness_center

Start training

Open Tracker, create your first plan and log your first set. No sign-up needed.

androidRequires Android 7.0 (API 24) or newer. Updates are published on the Releases page. To update, download the new APK and install it over the old one. Your data is kept.

Privacy

Your data never leaves your phone

There are no accounts, no cloud sync, no ads and no analytics. Everything is stored in a local database on your device, and you can delete all of it from Settings with one tap.
